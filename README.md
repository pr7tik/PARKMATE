## 📌 About the Project

PARK-MATE is a web-based campus parking management system designed to simplify parking for students and staff at Lovely Professional University.

The platform allows users to explore campus parking availability, select parking slots, make reservations, manage registered vehicles, and locate their parked vehicles through a centralized dashboard.

This project is developed as a demonstration prototype using browser-based storage and simulated campus parking data.


## ✨ Features

- **Demo Authentication** – Login using any non-empty User ID and password.
- **Interactive Parking Map** – Explore parking blocks, floors, zones, and individual slots.
- **Parking Reservations** – Select parking slots, dates, arrival times, and durations.
- **QR Booking Confirmation** – Generate QR-based booking references.
- **Vehicle Management** – Register and manage two-wheelers and four-wheelers.
- **Find My Vehicle** – Save and retrieve your parked vehicle's location.
- **Notification Center** – View booking updates and campus parking alerts.
- **User Profile** – Manage profile information and booking history.
- **Campus Navigation** – Explore simulated routes between campus locations.
- **Responsive UI** – Designed for desktop and mobile devices.
- **Cross-Tab Synchronization** – Keep booking information synchronized between browser tabs.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pr7tik/PARKMATE.git
```

### 2. Open the project

```bash
cd PARKMATE
```

### 3. Run the application

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in VS Code.

No backend installation or database configuration is required for the demonstration.
